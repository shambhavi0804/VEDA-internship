# Personal Information Web Application

## VEDA Internship Project

A simple Python Flask web application that accepts a user's basic information and displays it in a clean, formatted profile.

## Features

- Collects user's basic information
- Accepts name, age, email, phone, city, and occupation
- Converts age from form input to an integer
- Displays information in a formatted profile
- Responsive design
- Simple and beginner-friendly Flask application

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
